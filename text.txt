Title
Design and Develop a Real-Time Service Request Management System
Business Context
A growing service organization currently manages customer service requests manually, resulting in
delayed updates and poor visibility into request progress. The organization requires a web-based
system that enables operators to submit service requests while supervisors monitor processing in real
time.
The application should support multiple requests being processed simultaneously, provide live status
updates to connected users, and remain responsive while long-running operations execute in the
background.
The objective of this assignment is to evaluate the candidate's ability to analyze business requirements,
design an appropriate solution, and implement a working full-stack application using technologies of
their choice.
Candidate Objectives
● The candidate is expected to:
● Analyze the business problem.
● Define functional and non-functional requirements.
● Design the overall solution.
● Justify the selected technology stack.
● Implement the application.
● Demonstrate software engineering best practices.
● Present assumptions and design decisions.
Mandatory Technical Skills to Demonstrate
The implementation must demonstrate the following technical capabilities:
Backend
● RESTful API development
● Database design and integration
● Input validation
● Error handling
● Layered application architecture
● Configuration management
Frontend
● Responsive user interface
● API integration
● Form validation
● State management
● Real-time UI updates
Real-Time Communication (Mandatory)
The system must use WebSockets (or an equivalent real-time communication protocol) to push
updates from the server to connected clients.
Polling is not acceptable as the primary update mechanism.
Concurrent Processing (Mandatory)
The system must demonstrate concurrent execution using threads, background workers,
asynchronous tasks, or an equivalent concurrency mechanism supported by the chosen
technology stack.
Long-running processes must not block incoming API requests.
Database
● Appropriate schema design
● Data persistence
● Basic relationships and constraints
Software Engineering Practices
● Git version control
● Meaningful commit history
● Clear project structure
● Documentation

Prepare a short analysis document that includes:

● Business objectives
● Users
